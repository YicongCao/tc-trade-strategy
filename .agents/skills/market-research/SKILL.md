# 市场研究

先读 `dependencies/market-intelligence.md`，复用 `market-intelligence` 采集入口和已有原始快照。需要最新数据时重新采集，并单独标注来源滞后。

tc 提供行情抽查、近期新闻、市场概览及账户上下文；公开数据补充事件价格、跨资产行情和宏观指标。先发现当前工具，再按实际 schema 调用，不固定工具数量。

事件预测必须核验截止日、结算条件、流动性与价差；严格区分触价、收盘价和期限终值。板块收益与成交额不是净流入；ETF 净申赎不等于全部机构资金。

主题分析给出价格证据、新闻或原始披露、受益/受损篮子、反证与失效条件。AI 泡沫合约、研究预警阈值和估值模型分开呈现；未回测的门槛不能标为已验证交易信号。

结果写入普通 Markdown 或独立 HTML，遵循根目录 `AGENTS.md` 的报告约定。原始 JSON 留在 `results/` 供追溯，聊天只给主要结论和报告链接。此工作流不执行策略变更或交易。
