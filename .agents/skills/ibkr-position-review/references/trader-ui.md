## 仓位差异标签

仓位格观察到 `实际数量 / 对照数量` 形式，以及“需平仓”“需卖出 N 股”。非零对照时，显示差异与两数量相减一致，因而对照值**可能是换算目标仓位**；本次未核验其计算公式、来源、刷新周期或是否为最新目标。

- 用户约定：“需平仓”用于识别自主购买的额外标的。记录依据为用户说明，而非程序源代码验证。
- “需卖出 N 股”是界面对照差异，不是模型建议，也不证明该差额一定是用户主动加仓。
- 目标缺失或重新加载时，标签可能无法用于来源判断。观察中出现过配置空页与非零对照并存、返回页面后对照归零的现象；原因未核验，不诊断为真实清仓或程序故障。
- 对照目标不稳定时，保留用户解释，但将当次自动分类降级为待核实。不要从全部显示“需平仓”得出全部仓位都是自主交易。
- 页面仓位显示可能取整；市值计算需警惕碎股和显示精度。成本基础可能与会计报表不同，不能仅据差值认定错误。
