# 跟单观点的证据与归因

用户可能跟随第三方组合，同时自主买入额外标的。复盘应分别检查信号质量、复制执行与自主风险叠加，不能仅看账户盈亏评价信号提供者。

## 将叙事拆成可检验命题

| 命题类型 | 验证方式 | 避免的误读 |
|---|---|---|
| 连续下跌、均线、相对强弱、前期高点 | 明确指数/ETF、时区、复权与端点；按交易日计算 | SOX、SOXX、SMH 不可互换；“十几年最长”需要完整历史样本 |
| 机构接盘、出货、用大科技掩护 | 核验可得的持仓、资金流和主体证据，标明窗口与滞后 | 价格轮动不能识别参与者意图；13F 不能还原逐日交易 |
| 支撑区、反弹到均线、再次探底 | 记录观点提出时点、预测窗口、价格区间、确认与失效条件 | 支撑不是保证成交的底部；未出现反弹不构成“只有一种可能” |
| 波浪标签、季节性反弹与特定月份下跌 | 作为情景，明确何种观测会推翻 | 波浪名称不提供客观概率；不按日期安排必然顶部或底部 |
| 财报、FOMC、IPO 与选举 | 分别查公司 IR、美联储、正式发行/监管文件与官方日历 | 传闻不是已安排事件；事件落地不保证利空出尽 |
| 硬件降价、资本开支与应用利润 | 区分供给增加、需求下降和效率提升；分开客户与供应商 | 硬件成本下降可利好应用而损害供应商利润；AI 发展不等于所有 AI 股上涨 |
| 区域或行业风险排序 | 分解负债、融资期限、客户集中、估值、币种、地缘与产品周期 | 国别或“避险板块”标签不能替代公司分析；能源、黄金股与现金风险不同 |

## 复盘对照

尽可能按同一时间线保留：观点发表 → 信号组合变化 → 程序目标变化 → 订单提交 → 实际成交 → 用户额外操作。缺少某环节就标缺失，不补造。

当股票同时有跟单与自主仓、或曾经由跟单转为自主保留时，当前页面标签不能恢复全部历史归属。只有能匹配来源与时间的记录，才可比较成交延迟、滑点、费用、漏单、比例偏差及自主覆盖的影响。

为每个关键预测写：原命题、证据、反证、观察期限、当前状态（未验证／支持／削弱／失效）、账户风险含义。复核时保留原命题，不事后修改价格区间或日期来迁就结果。
