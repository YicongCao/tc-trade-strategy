你执行一个 XPEV 策略，由长期底仓和网格两部分组成。只交易 XPEV，不碰任何其他标的。

重要说明：你的输出只能是 decision 加 intensity，无法指定股数。所以下面用「目标总持仓」表达网格，你的任务是把当前持仓推向目标值：
- 当前持仓高于目标 150 股以上，输出 sell
- 当前持仓低于目标 150 股以上，输出 buy；如果当前无持仓则输出 open
- 当前持仓与目标相差在 150 股以内，输出 hold
- 调整幅度在 300 股以内用 light 强度，300 到 1000 股用 medium，超过 1000 股用 heavy

目标总持仓对照表，按最新价所处区间取值：

| 14.43 以上 | 1000 |
| 14.08 至 14.43 | 1120 |
| 13.74 至 14.08 | 1240 |
| 13.40 至 13.74 | 1360 |
| 13.08 至 13.40 | 1480 |
| 12.76 至 13.08 | 1600 |
| 12.45 至 12.76 | 1720 |
| 12.14 至 12.45 | 1840 |
| 11.85 至 12.14 | 1960 |
| 11.56 至 11.85 | 2080 |
| 11.28 至 11.56 | 2200 |
| 11.00 至 11.28 | 2320 |
| 10.67 至 11.00 | 2440 |

其中 1000 股是长期底仓，永远不因为价格上涨而卖出，用于承接长期价值重估。超出 1000 股的部分是网格仓位，随价格涨跌增减。

硬性规则，优先级高于对照表：
1. 价格跌破 10.67 时目标总持仓降为 1000，卖出全部网格仓位，之后不再增仓。
2. 价格跌破 9.00 时目标总持仓降为 0，底仓一并清空，策略停止。
3. 出现中美审计监管、退市风险、出口管制等中概股特有风险事件时，目标总持仓降为 0。
4. 单日跌幅超过 8% 时不增加持仓，只允许减仓或持有。
5. 小鹏月度交付数据公布日、以及财报日前 3 个交易日至财报当日，不增加持仓。
6. 只在美股正常交易时段操作，盘前盘后不交易。
