## 核心理念

> 系统不预测市场。你的工作是：判断当前方向偏好 → 等待一根顺向K线 → 在合理位置入场 → 用结构管理止损和止盈。


---

## 第一步：判断方向（每根K线收盘时）

看最近10根K线：

| 观察到 | 方向判断 |
|--------|---------|
| 多数K线收盘高于前一根收盘，高点低点整体上移 | **偏多** |
| 多数K线收盘低于前一根收盘，高点低点整体下移 | **偏空** |
| 高低点反复重叠，收盘没有明确方向 | **震荡**（可以双向做，目标缩小） |
| 连续5根以上同向收盘且实体大 | **强趋势**（加大仓位或放宽目标） |

**方向判断是偏好，不是门槛。** 震荡区间也可以做，只是目标缩小到1-2点。

---

## 第二步：识别信号K线

**做多信号K线**：阳线（收盘 > 开盘），实体越大越好。
**做空信号K线**：阴线（收盘 < 开盘），实体越大越好。

**这就是最低门槛。** 有方向有实体即可。

**信号强度分级**（影响仓位和目标，不影响是否触发）：

| 等级 | 特征 | 操作 |
|------|------|------|
| 强信号 | 大实体（占K线高度60%+），收在高点/低点附近，影线短 | 正常仓位，目标可以放大到MM |
| 中等信号 | 中等实体，方向明确 | 正常仓位，目标1:1到1:2 |
| 弱信号 | 小实体，长影线，十字星 | 缩小仓位或跳过，目标缩小到Scalp |

**不要因为信号"不够完美"就不做。** 方方土实盘中，10笔有7笔的信号K线不完全满足教科书标准。关键是方向对、有结构支撑。

---

## 第三步：检查是否有Setup结构（置信度放大器）

以下Setup不是入场的必要条件。**它们的作用是：如果出现，说明这笔交易胜率更高、可以加大仓位或放大目标。** 没有Setup也能入场——只要方向对+有信号K线+不在铁丝网里。

### ★★★ 高置信度Setup（出现时可以加大仓位）

**1. 楔形反转 / 三推反转**
- 趋势中出现三段同向push，第三段衰竭
- 反转信号K线出现 → 逆前趋势方向入场
- 止损：第三推极值外1-2 tick
- 目标：前一波段的50%回撤，强的时候拿MM
- 回测PF 8-28，唯一跨品种正收益

**2. 大K线突破 / Bear/Bull Surprise**
- 出现一根远超正常大小的K线（实体是前5根平均的150%+）
- 方向与趋势一致 → 顺势Stop Order入场
- 方向与趋势相反 → 可能是反转信号，等确认后反手
- 止损：大K线极值外1 tick（大K线本身保护性好）
- 目标：大K线实体幅度的1-2倍

**3. Final Flag（末端旗帜）反转**
- 趋势末端出现2-5根小K线（Inside Bar或极窄区间）
- 向趋势反方向突破 → 反转入场
- 止损：窄区间极值外1 tick（非常小）
- 目标：前趋势的50%-100%回撤（盈亏比极高）

### ★★☆ 中置信度Setup（正常仓位）

**4. EMA20回踩**
- 价格回到EMA20附近 + 出现顺向信号K线
- 入场：信号K线极值外1 tick Stop Order
- 止损：EMA20另一侧2-3 tick
- 目标：5-10 tick

**5. 第三推（3rd Push）**
- 趋势中两次同向push后，第三次push衰竭
- 反转信号K线出现 → 逆势入场
- 止损：第三推极值外1 tick
- 目标：前波段高度的等幅投射

**6. BOM突破（开盘专用）**
- 第1根15min K线的高低点被双向突破失败
- 之后向一个方向强势突破 → 顺势入场
- 止损：BOM区间另一侧
- 目标：区间高度×2（Measured Move）

**7. 突破失败 / Bear Trap / Bull Trap**
- 创新高/低但收盘弱（反向小实体或十字星）
- 1-3根内被反向吞回 → 反向入场
- 止损：假突破极值外1 tick
- 目标：前一波段的38%-50%回撤

### ★☆☆ 补充Setup（轻仓或观察）

**8. 双顶/双底**
- 两次测试同一水平失败 + 颈线突破
- 入场：颈线突破方向Stop Order
- 止损：双顶/底极值外1 tick

**9. High 2 / Low 2**
- 趋势中两次回调后顺势入场
- 入场：第二次回调结束后的顺向信号K线外1 tick

**10. 反手（Reverse）**
- 原仓位止损 + Always In翻转 + 出现反向信号K线
- 反手仓位可以大于原仓（2:1）
- 这是方方土实盘高频使用的操作

## 第四步：入场执行

### 入场方式（选最合适的）

| 场景 | 方式 | 位置 |
|------|------|------|
| 强信号 + 想确保入场 | Stop Order | 信号K线高点上方1 tick（做多）/ 低点下方1 tick（做空） |
| 想在更好价格入场 | Limit Order | 信号K线开盘价附近，或EMA20附近 |
| 极强信号不想错过 | Market Order | 信号K线收盘时直接入场 |

**三种方式都可以，取决于信号强度和个人偏好。不要纠结方式。**

### 仓位规则

- 标准仓位：账户风险的1-2%（单笔最大亏损）
- 高置信度Setup（★★★）：可以用标准仓位的1.5倍
- 弱信号或震荡区间：缩减到标准仓位的1/2
- 波段目标很大时（预期10+点）：缩小仓位保持风险不变

---

## 第五步：止损与离场

### 初始止损

放在**你的交易前提失效的地方**：
- 顺向入场 → 止损在信号K线极值外1-2 tick
- 反转入场 → 止损在反转结构（楔形/双顶/三推）的极值外1-2 tick
- 如果止损距离太大（> 4点）→ 缩小仓位而非放宽止损

### 止损调整

| 情况 | 动作 |
|------|------|
| 利润达到1倍初始风险 | 止损移到盈亏平衡 |
| 强趋势中创新高/低 | 止损移到最近波段极值外1 tick |
| 连续2根K线收在EMA20另一侧 | 考虑离场或反手 |
| 入场后4-6根K线没有朝有利方向走 | 前提可能错了，离场 |

### 止盈

**分批止盈，不要试图吃满：**
- 利润2点 → 可以先出1/3
- 利润4点 → 再出1/3，剩余止损移到成本
- 剩余 → 持到出现反转信号或达到MM目标

**Measured Move（MM）计算：**
- 区间/震荡突破：区间高度×2
- 两段趋势：AB = CD（第一段幅度 = 第二段目标）
- 大K线突破：大K线实体×2

---

## 第六步：不做的情形

**只有这5个是硬性禁止：**

1. **铁丝网（Barbwire）**：5根以上K线大幅重叠+多十字星 → 机构在收割，停止操作
2. **重大事件前后**：FOMC、非农等 → 等事件过去
3. **完全没有方向偏好+没有信号K线** → 不做
4. **前一笔亏损后立刻想做一笔大的回来** → 强制等3根K线
5. **止损距离超过4点但不愿缩小仓位** → 要么缩小仓位要么不做

**注意：逆势交易不在禁止列表里。** 反转交易（楔形反转、第三推、Final Flag）本质上就是逆势的。方方土靠反转交易赚了大钱。关键是反转要有结构支撑（三推/双顶/末端旗帜），不是凭感觉"跌够了"就抄底。

---

## 执行清单（每根15min K线收盘）

```
1. 方向：最近10根K线偏多/偏空/震荡？
2. 当前K线：是否是信号K线（阳线/阴线有实体）？
3. 如果是 → 是否有Setup结构放大置信度？
4. 如果不是 → 跳过，等下一根
5. 确认不在禁止情形中（铁丝网/事件/情绪化）
6. 决定入场方式、仓位、止损、目标
7. 入场后：每根K线收盘检查止损调整和离场信号
```
